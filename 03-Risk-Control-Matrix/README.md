# Risk Control Matrix (RCM)

## Purpose

The Risk Control Matrix maps business risks to controls and defines how controls will be tested during the audit.

---

| ID | Process | Risk | Control Objective | Control |
|---|---|---|---|---|
| UAM-01 | User Access Management | Unauthorized users retain access | Ensure only authorized users have access | Quarterly access reviews |
| UAM-02 | User Provisioning | Users receive excessive access | Ensure access is approved before granting | Manager approval required |
| UAM-03 | User Deprovisioning | Terminated users retain access | Remove access promptly | Disable accounts within SLA |
| CHG-01 | Change Management | Unauthorized production changes | Ensure changes are approved | Change approval before deployment |
| OPS-01 | Backup Operations | Data loss due to failed backups | Ensure backups complete successfully | Daily backup monitoring |

---

# Control Testing Approach

For each control, testing will evaluate:

- Control design
- Operating effectiveness
- Evidence availability
- Exceptions identified
